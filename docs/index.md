# λLoop Documentation

Welcome to the documentation for the λLoop library.

λLoop provides a fluent and expressive way to create loops in Java.

![Avoiding Java Streams with &#955;Loop](images/no-stream.png)
_&#955;Loop promotes a more readable and efficient way to handle common looping constructs, often eliminating the need for verbose Stream API usage in simple scenarios._
